<Steps>
  <Step title="Install Lightnovel Crawler">
    Install the `lightnovel-crawler` package from PyPI. See the [installation guide](/installation) for all available methods including standalone binaries and Docker.

    ```bash
    pip install -U lightnovel-crawler
    ```

    Verify the installation:

    ```bash
    lncrawl -h
    ```
  </Step>

  <Step title="Search for a novel">
    Use the `search` command to find novels by title across all supported sources:

    ```bash
    lncrawl search "mushoku tensei"
    ```

    The search results will list matching novels with their source URLs. Copy the URL of the novel you want to download and use it in the next step.
  </Step>

  <Step title="Crawl a novel URL">
    Pass the novel's detail page URL directly to the `crawl` command:

    ```bash
    lncrawl crawl https://example.com/novel/mushoku-tensei/
    ```

    lncrawl will fetch the novel metadata (title, author, cover, chapter list) and display a summary before proceeding.
  </Step>

  <Step title="Select chapters">
    In interactive mode, lncrawl prompts you to select which chapters to download. You can:

    - Download **all** chapters
    - Enter a **range** (e.g. `1-50`)
    - Pick **individual** chapter numbers

    To skip the prompt entirely, use `--all`, `--first N`, or `--last N` flags (see [non-interactive mode](#non-interactive-mode) below).
  </Step>

  <Step title="Choose an output format">
    When prompted, select your desired output format. The following formats are available:

    | Format | Notes |
    |--------|-------|
    | `epub`  | Most compatible — works on Kindle, Kobo, and all major e-readers |
    | `txt`   | Plain text, no external tools required |
    | `json`  | Raw structured data |
    | `pdf`   | Requires Calibre |
    | `mobi`  | Requires Calibre |
    | `docx`  | Requires Calibre |
    | `rtf`   | Requires Calibre |
    | `fb2`   | Requires Calibre |
    | `azw3`  | Requires Calibre |
    | `lit`   | Requires Calibre |
    | `lrf`   | Requires Calibre |
    | `pdb`   | Requires Calibre |
    | `rb`    | Requires Calibre |
    | `tcr`   | Requires Calibre |

    <Note>
      PDF, MOBI, DOCX, and most other formats (except `epub`, `txt`, and `json`) require [Calibre](https://calibre-ebook.com/download) to be installed and available on your system PATH. On macOS, you may need to run `export PATH="$PATH:/Applications/calibre.app/Contents/MacOS"` before starting lncrawl.
    </Note>

    <Tip>
      EPUB is the most compatible format. It works natively on Kindle (via Send to Kindle or sideloading), Kobo, Apple Books, and virtually all e-reader apps. Start with EPUB unless you have a specific format requirement.
    </Tip>
  </Step>

  <Step title="Open the output folder">
    Once the download completes, lncrawl prints the path to the output folder and offers to open it. Output is saved to `~/Downloads/lightnovel-crawler/<novel-title>/` by default.

    You can also open the folder manually or configure a custom output path via `lncrawl config`.
  </Step>
</Steps>

## Non-interactive mode

Use `--noin` to skip all prompts and run fully automated. Combine it with chapter selection and format flags:

<CodeGroup>

```bash Download all chapters as EPUB
lncrawl crawl --noin --all -f epub https://example.com/novel/some-title/
```

```bash Download first 10 chapters as EPUB
lncrawl crawl --noin --first 10 -f epub https://example.com/novel/some-title/
```

```bash Download last 5 chapters as plain text
lncrawl crawl --noin --last 5 -f txt https://example.com/novel/some-title/
```

```bash Download all chapters in multiple formats
lncrawl crawl --noin --all -f epub -f mobi https://example.com/novel/some-title/
```

</CodeGroup>

**Key flags reference:**

| Flag | Description |
|------|-------------|
| `--noin` | Disable interactive mode — required for scripting or automation |
| `--all` | Download all available chapters |
| `--first N` | Download the first N chapters (e.g. `--first 10`) |
| `--last N` | Download the latest N chapters (e.g. `--last 5`) |
| `--format` / `-f` | Output format; can be repeated for multiple formats |

## Running as a web server

lncrawl includes a built-in web interface. Start the server with:

```bash
lncrawl server
```

Then open [http://localhost:8080](http://localhost:8080) in your browser.

**Default credentials:**

```
username: admin
password: admin
```

You can specify a custom port with the `-p` flag:

```bash
lncrawl -ll server -p 8080
```

To run the server with Docker:

```bash
docker run -v ~/.lncrawl:/data --rm -it -p 8080:8080 ghcr.io/lncrawl/lightnovel-crawler server
```
